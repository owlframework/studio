# Security Policy

| Version | 
| ------- |
| 1.0.1   |
| 1.0.0   | 

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub Issues, Discussions, or Pull Requests.**

If you discover a security vulnerability within Owl Framework (`owlframework/core` or `owlframework/studio`), please report it privately using one of the following methods:

1. **GitHub Private Vulnerability Reporting (Preferred):** Navigate to the **Security** tab of this repository and click **"Report a vulnerability"** to submit a private advisory.
2. **Email:** Send a detailed report to **security@owl.ng** *(update this to your preferred active contact email)*.

### What to Include in Your Report
To help us reproduce and resolve the issue quickly, please include:
* A clear description of the vulnerability and its potential impact.
* Step-by-step instructions or a proof-of-concept script to reproduce the issue.
* The affected repository (`core` or `studio`), version number, and PHP environment details.

### Response & Disclosure Timeline
* **Acknowledgment:** You will receive a confirmation that we have received your report within **48 hours**.
* **Investigation & Updates:** We will evaluate the report and provide status updates at least once every **5 business days** until a resolution is reached.
* **Resolution:** Once a patch is verified and released, we will publicly disclose the fix in our release notes and credit you for the discovery (unless you prefer to remain anonymous).
